This is a copy of Óscar Toledo Gutiérrez' cc1 Transputer compiler, which is being ported to the platforms I use for
the Parachute project, and translated from Spanish to English. See the `cc1_es` directory for the initial Spanish
version. Original sources at https://github.com/nanochess/transputer.git

Translation status:
* All messages to the user translated from Spanish to English with help from Google Translate.
* Where there is a choice of Si/No/Pasar de largo, this has been translated to Yes/No/Skip.

-- Matt Gumbley, 18/09/2026
